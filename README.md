## 概要

<!-- アプリの概要を2〜3行で記入してください -->

1問1分の詰将棋を、ショート動画のように縦スワイプで次々に解く iOS アプリです。問題はアプリがその場で自動生成するので尽きません。最初は渋い和紙の見た目で、詰ませた瞬間にネオンの見た目と BGM に切り替わり、「渋い」詰将棋を気持ちよく遊べるものにしました。

## 技術的に工夫した点・苦労した点

<!-- 審査で重視される項目です。具体的に記入してください -->

### 工夫した点

- 詰将棋を解くソルバーと、問題を作るジェネレーターを自作しました。駒をランダムに置いてソルバーにかけ、「正解の初手が1つだけ」「早詰めがない」「3手詰めは最終手も1つ」などの条件を満たす局面だけを出題します。既存の作品を使わないので著作権の問題がなく、問題が尽きません
- 次の3問を裏のスレッドで作り置きして、スワイプしても待たされないようにしました
- 初心者向けに 5×5・7×7 の小さい盤を用意し、見えている範囲を盤の端（壁）にして、見えているマスだけ考えれば解けるようにしました
- 「渋い」から「派手」への落差を演出にしました。初回は普通の見た目・無音で始め、1問目を詰ませた瞬間にネオンの見た目へ切り替わり、BGM が流れ始めます
- 手応えを重ねました。詰みの音は連勝ごとにドレミの音階で上がり、振動は連勝 3・5・10 で強くなり、最後の一手から Metal の波紋が広がります
- 間違えたときは、正解の手と玉方の防ぎ方（「6一へ逃げられます」など）を盤の上で見せ、なぜ詰まないかがわかるようにしました
- 7段階の入門と、ノーマルで間違えた問題だけを解き直す修行モードを用意しました

### 苦労した点

- 自動生成した問題の質です。正解が複数ある・1手早く詰む・王手の候補が少なすぎる局面を除く条件を詰め、生成した問題が条件を満たすことを Mac のコマンドラインのテストで毎回確かめるようにしました
- 小さい盤で、画面では詰んでいるのに見えないマスへ玉が逃げて不正解になる問題がありました。局面に盤の大きさを持たせ、範囲の外へはどちらの駒も動けないようにして直しました
- 連勝で詰みの音を高くしようとしたところ、AVAudioPlayer の速度変更では音の高さが変わらず、AVAudioEngine の Varispeed に作り直しました
